# Task Management

This context describes the language for capturing and tracking a small set of personal tasks. It exists to keep product wording consistent across planning, implementation, and testing.

## Language

**Task List**:
The single collection of Tasks managed by the application.
_Avoid_: Todo List, ToDo List, checklist

**Task**:
An actionable item recorded in the Task List.
_Avoid_: Todo, ToDo item, entry

**Task Title**:
The short text that identifies a Task to the user.
_Avoid_: Name, label, description

**Task Status**:
The current lifecycle state of a Task: Active or Completed.
_Avoid_: State, done flag

**Active**:
The Task Status for work that remains to be completed.
_Avoid_: Pending, incomplete, open

**Completed**:
The Task Status for work the user has finished.
_Avoid_: Done, closed, resolved
